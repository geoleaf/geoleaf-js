| `nom` | `ok` / `KO` — le nom permet-il de prédire le contenu ? |
| `emp` | `ok` / `KO` — l'emplacement est-il celui qu'on irait chercher ? |
| `existence` | `justifié` · `renommer` · `déplacer` · `fusionner` · `supprimer` · `?` non qualifié |
