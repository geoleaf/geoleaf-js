## Mode d'emploi (sprints B/C)

- **Une famille de fichiers par sprint** d'inventaire (B1→B7). Pour chaque clé : grep des consommateurs réels dans `packages/core/src` (et les plugins pour B7) → `fichier:ligne`, puis remplir une ligne du tableau de la section correspondante.
- Tout écart (orphelin, alias, légacy, cassé, duplicata) → **consigner aussi** dans `registre_anomalies_config.md`.
- Le garde-fou `check-config-coverage.cjs` (introduit en B) **échoue** si une clé présente dans le code ou un schéma n'a **pas** de ligne ici.
- En Phase C, cocher la colonne **Testé** au fur et à mesure que chaque valeur est couverte (Vitest câblage + E2E/UX effet).

## Conventions (figées S0)

### Format de ligne d'inventaire

`fichier · clé (chemin pointé) · type · valeurs possibles (enum/range) · défaut · consommateur file:line · statut · effet observable` — plus une colonne **Testé** (Phase C).

### Grille de statuts

| Statut                    | Signification                                                                 |
| ------------------------- | ----------------------------------------------------------------------------- |
| ✅ utilisé                | Clé lue par un consommateur actif — effet observable au runtime               |
| 🟡 partiel                | Lue mais implémentation incomplète / incohérence de nommage                   |
| ⚪ orphelin (schéma-only) | Présente dans un schéma (et/ou un profil) mais **aucun** consommateur runtime |
| 🟥 consommateur-mort      | Un consommateur existe mais sur un chemin d'exécution mort                    |
| 🔁 alias/duplicata        | Fonctionne mais redondante avec une clé canonique (canonique en note)         |
| 🕯️ légacy-déprécié        | Conservée pour compat ; remplacée par une clé/mécanisme plus récent           |
| ❌ cassé (no-mapping)     | Consommateur présent mais sans effet (ex. non mappé vers MapLibre)            |

### Colonne « Testé » (Phase C)

`☐` non couvert · `☑ unit` câblage Vitest · `☑ e2e` effet vérifié Chromium · `☑ ux` observation headless · cumulables.
